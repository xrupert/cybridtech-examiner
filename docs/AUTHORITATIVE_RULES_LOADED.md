## State-law dependencies

The Quick Reference Checklist calls for state-rule research where a requirement depends on state law. The current MVP does not silently invent or simulate those mandates. Unless an authoritative state rule has been loaded for the specific issue, the application must leave that dependency for manual verification rather than manufacture a PASS or FAIL.

## Change control

These normalized rules are treated as the active audit constitution for this version. Changes require a new rule-version identifier so historical reviews can be tied to the rule set that produced them.
