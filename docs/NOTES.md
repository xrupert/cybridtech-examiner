# MVP Non-Goals

Not part of this release unless validation proves them necessary:

- 16-agent or multi-agent workforce
- dedicated OCR vendor
- automated state-law web search deciding PASS/FAIL
- universal Elite rules
- 2nd Lien Limited VERA report
- multi-tenant billing/customer portal
- bulk job queue
- pixel bounding-box highlighting

The MVP target remains one defensible title workflow end to end before platform expansion.
